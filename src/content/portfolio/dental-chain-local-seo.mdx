## The Challenge

A 45-location dental group had a single generic page with a location finder. No city-specific pages, no local schema, no Google Business Profile optimisation — each location was effectively invisible in local search.

## Our Approach

### Programmatic Page Generation
We built a template system that generates unique landing pages for each location:
- City-specific content and copy
- Local testimonials and case studies
- Area-specific service offerings
- Driving directions and landmark references

### Schema Automation
Every location page received full `LocalBusiness` schema:
- Name, address, phone, hours
- Geo coordinates for map placement
- `areaServed` with city/neighborhood data
- `medicalBusiness` specific properties

### Monitoring Pipeline
An n8n workflow monitors all 120+ pages:
- Daily HTTP status checks
- Weekly Core Web Vitals audits
- Monthly AI crawl frequency tracking
- Quarterly content freshness reviews

## What the build delivers

| Deliverable | Scope |
|--------|--------|
| City pages | 120+ generated from one data template |
| Schema | Full `LocalBusiness` on every page |
| Monitoring | n8n checks status + Core Web Vitals daily |
| Cost to add a location | Effectively zero — auto-generated |
| Page speed | Lighthouse 96, LCP 0.6s |

Ranking and traffic outcomes depend on the market, competition and the client's existing review profile — we report those per engagement rather than promise them here.
